# Mixed-State Bootstrap
1. `test16/test16-A.m` is the PMP generator of bootstrap equation of the linear trajectory in the massive scalar scattering.

2. `test16/test16-B.m` is the PMP generator of bootstrap equation of the linear trajectory in the massless scalar scattering.

3. `test18/test18.m` is the PMP generator of the bootstrap equation of the linear trajectory in the mixed-state scattering, and I have included the null constraints of the AB -> AB scattering, which should be non-trivial constraints.

4. `AAAA_sum_rules.m` includes the generator of the null constraints from the massive scalar scattering.

5. `BBBB_sum_rules.m` includes the generator of the null constraints from the massless scalar scattering.

6. `ABAB_calculations.m` includes the generator of the null constrains from the mixed-state scattering. I suspect that there is one null constraint that linearly depends on the others.
